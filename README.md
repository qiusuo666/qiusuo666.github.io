# 新标签页 (Custom Tabs)

一个精美的浏览器新标签页替代品，支持多端数据同步、书签导入导出、便签管理和响应式适配。

## ✨ 功能

### 时间与搜索
- **数字时钟** — 大字号渐变时钟 + 日期显示，每秒刷新
- **6 大搜索引擎** — Google / 百度 / Bing / DuckDuckGo / 搜狗 / 360，一键切换
- **搜索历史** — 自动记录搜索关键词，支持悬停删除和一键清空
- **搜索建议** — 输入时根据历史记录实时联想

### 快捷网址管理
- **自定义分类** — 创建/重命名/删除分类，灵活组织网址
- **网址卡片** — 彩色首字母图标，悬停展示删除按钮，拖拽排序、跨分类移动
- **常用快捷栏** — 底部常驻收藏栏，拖入网址即可钉选，支持横向滚动和内部排序
- **快捷网址页** — 主界面右键或长按进入，管理所有网址和分类
- **右键菜单** — 卡片右键：删除/编辑/添加到常用；分类标题右键：重命名/删除分类
- **编辑网址** — 支持选择分类、URL 自动补全 `https://`

### 美化与个性化
- **壁纸系统** — 5 张内置壁纸（梵高星空/暮光森林/樱花街道/海岸晚霞/雪山镜湖）+ 自定义上传
- **Bing 每日壁纸** — 自动获取 Bing 每日精选壁纸，支持多级代理回退，每日缓存更新
- **粒子背景** — 鼠标排斥 + 静止潮汐聚散模式的浮动粒子动画，数量根据屏幕自适应
- **背景设置面板** — 右侧抽屉式面板，实时预览和切换壁纸

### 便签系统
- **📝 快速便签** — 左上角按钮打开，实时输入即保存，无需手动点击
- **钉固到主屏幕** — 关键便签钉固后以毛玻璃卡片展示在主界面左上角
- **多端同步** — 便签数据随账号自动同步到云端
- **目录管理** — 左侧目录栏 + 右侧编辑器，比例 1:2 布局
- **移动端滑动隐藏** — 向左滑动钉固区可隐藏，展开把手一键恢复

### 书签导入导出
- **📤 导出为浏览器书签** — 一键导出为标准 `Netscape HTML` 格式，可直接导入 Chrome/Edge/Firefox，保留分类结构
- **📥 导入浏览器书签** — 支持导入 Chrome/Edge/Firefox 导出的书签文件，自动还原分类（纯正则解析，跨浏览器兼容），智能去重
- **纯文本解析** — 不依赖 DOM 解析器，兼容大文件（500KB+），Edge/Chrome/Firefox 全兼容

### 账号与同步
- **🔐 账号登录** — 用户名+密码注册/登录（无需邮箱验证）
- **记住登录** — 可选持久会话，关闭页面后仍保持登录
- **☁️ 多端同步** — 登录后自动同步分类、收藏、搜索历史、搜索引擎偏好、便签数据（3 秒防抖）
- **手动同步** — 用户菜单中可手动上传/下载
- **修改密码** — 已登录状态下可修改密码
- **RLS 安全策略** — 数据库层强制用户数据隔离，A 用户无法读取 B 用户数据

### 响应式适配
- **桌面端** — 完整功能体验，便签面板 650px 宽、1:2 目录/编辑比例
- **平板端 (≤768px)** — 时钟 52px、搜索框优化、面板自动上移避免遮挡、钉固区可滑动隐藏，便签面板 30/70 比例
- **手机竖屏 (≤480px)** — 时钟 36px、搜索框全宽、3 列网址卡片、便签面板垂直堆叠、弹窗全屏适配

### 移动端交互
- **长按 500ms** — 网址卡片 → 弹出编辑菜单；主界面空白 → 进入快捷网址页
- **快捷网址入口按钮** — ≤768px 时右上角显示 📱 按钮
- **触摸振动反馈** — 长按时触发触觉反馈
- **触摸拖拽** — 拖拽卡片时阻止页面滚动
- **钉固区滑动隐藏** — 向左滑动 40px 隐藏钉固区，展开把手恢复
- **便签删除按钮** — 触摸设备上删除按钮始终可见（`@media (hover: none)` 规则）

## 🚀 快速开始

### 本地使用

1. 克隆仓库
2. 用浏览器打开 `index.html`
3. （可选）将浏览器新标签页扩展指向本地文件，或部署到 GitHub Pages

### 作为 Chrome/Edge 新标签页

可以使用 [New Tab Redirect](https://chromewebstore.google.com/detail/new-tab-redirect/icpgjfneehieebagbmdbhnlpiopdcmna) 扩展将新标签页重定向到部署地址。

## ☁️ 多端同步

项目使用 [Supabase](https://supabase.com) 作为后端：

| 功能 | 说明 |
|------|------|
| 用户注册/登录 | 用户名 + 密码（无需邮箱验证） |
| 记住登录 | 可选持久会话，跨页面刷新保持登录 |
| 自动同步 | 数据变更后 3 秒防抖自动上传 |
| 手动同步 | 用户菜单中可手动上传/下载 |
| 修改密码 | 支持在已登录状态下修改密码 |
| 数据安全 | RLS 行级安全策略，用户间数据完全隔离 |

### 自建同步服务

1. 在 [Supabase](https://supabase.com) 创建项目
2. 执行 `supabase-setup.sql` 中的建表语句
3. 在 Dashboard → Authentication → Providers → Email 中关闭 **Confirm email**
4. 修改 `supabase-client.js` 中的 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`

## 📁 项目结构

```
Custom tabs/
├── index.html           # 主页面
├── style.css            # 样式表（含完整响应式适配）
├── script.js            # 主逻辑（搜索、时钟、壁纸、快捷栏、粒子、导入导出、认证UI、便签）
├── supabase-client.js   # Supabase 认证 + 云端同步 API
├── supabase-setup.sql   # 数据库建表 + RLS 策略（供自建参考）
├── photos/              # 内置壁纸图片
├── 历史存档/            # 开发过程备份版本
└── README.md
```

## 🤝 桌面端操作说明

| 操作 | 方式 |
|------|------|
| 进入快捷网址页 | 主界面右键 / 鼠标侧键 |
| 返回主界面 | 点击快捷网址页空白区域 / Esc |
| 搜索 | 输入关键词 + Enter 或点击搜索图标 |
| 添加快捷网址 | 快捷网址页 → 点击 + 号卡片 |
| 删除网址 | 悬停卡片 → 点击红色 ✕ 号 |
| 添加到常用栏 | 拖拽卡片到底部常用栏 / 右键添加到常用 |
| 导入书签 | 邮箱网址页 → 📥 导入按钮 |
| 导出书签 | 邮箱网址页 → 📤 导出按钮 |
| 更换壁纸 | 右上角 🖼 按钮 → 选择壁纸 / Bing 每日 |
| 更换搜索引擎 | 点击搜索框左侧引擎图标 |
| 登录/同步 | 右上角 👤 按钮 |
| 便签 | 左上角 📝 按钮 → 输入即保存 → 📌 钉固到主屏幕 |

## 🛠 技术栈

| 类别 | 技术 |
|------|------|
| 前端 | 原生 HTML / CSS / JavaScript（无框架） |
| 后端/认证 | [Supabase](https://supabase.com) (Auth + PostgreSQL) |
| 字体 | Google Fonts (Inter) |
| 图标 | 内联 SVG |
| 存储 | localStorage（本地） + Supabase JSONB（云端） |
| 书签 | Netscape HTML 格式（正则解析，支持跨浏览器） |
| 壁纸 | Bing API（多级 CORS 代理回退） |
